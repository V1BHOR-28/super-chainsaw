# Audiobook-maker (Flask) — consolidated Python dependencies.
#
# This file is the single source of truth for the Flask backend's Python deps.
# Previously, render.yaml's buildCommand installed most packages inline and
# requirements.txt only had a small subset — which meant a `pip install -r
# requirements.txt` alone (as used by Docker and local dev) was missing most
# of what the code actually imports. Consolidating here so both Render and
# Docker build from the same list.
#
# Install (dev):     pip install -r requirements.txt -r requirements-dev.txt
# Install (prod):    pip install -r requirements.txt
# Tests:             pytest tests/
