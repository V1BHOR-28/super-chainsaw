# Background Music (BGM) Loops

Place your royalty-free ambient audio loops in this folder.

### Expected Files:
- `fantasy.ogg` — Fantasy / mystical ambiance
- `scifi.ogg` — Sci-Fi / futuristic synth ambiance
- `mystery.ogg` — Mystery / suspenseful ambiance
- `romance.ogg` — Romance / soft acoustic ambiance
- `classic.ogg` — Classic / orchestral / piano ambiance
- `adventure.ogg` — Adventure / upbeat ambient loop

### Loop Recommendations:
- **Format**: `.ogg` or `.mp3` (if changing extensions in `player-view.tsx`)
- **Duration**: 30–60 seconds seamless loop
- **Volume**: Mastered quiet (around -20 LUFS) so narration remains crisp and clear
- **Royalty-Free Sources**: [Pixabay Music](https://pixabay.com/music/), [Free Music Archive](https://freemusicarchive.org/), [Freesound](https://freesound.org/)
